# gogo

A simple starter project.

## Getting Started

Clone the repository and open `index.html` in your browser, or run the Node.js entry point:

```bash
node index.js
```

## Project Structure

```
gogo/
├── index.html   # Browser entry point
├── index.js     # Node.js entry point
└── README.md    # This file
```
